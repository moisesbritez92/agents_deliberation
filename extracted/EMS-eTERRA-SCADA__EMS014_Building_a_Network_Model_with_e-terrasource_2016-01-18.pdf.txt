Document Conventions 
The following conventions are used throughout this document. 
 
Pull-down menu A greater-than symbol ( > ) and italics are used to 
indicate pull-down menu paths. 
For example: 
     Analyst Displays>Mode Modeling>Mode Directory 
 
Soft keys or 
buttons on a 
display 
Bold formatting is applied to indicate a selectable point. 
For example: 
     Apply 
 
Physical key on 
the keyboard 
A box is placed around the text that appears on the 
actual key on the keyboard. 
For example: 
     Enter 
 
Text to be entered 
verbatim by the 
student, or 
examples of code 
The code example style is used, which applies the 
monospaced font “Courier New.” 
For example: 
     Host: PC1392 
     Account: Student1 
     Password: escatrain 
 
< > Text enclosed in angle brackets ( < > ) indicates 
information you must supply. 
 
[ ] Square brackets ( [ ] ) indicate optional qualifiers, 
arguments, or data.

Graphic Modeler Basics:
The Graphic Modeler component of the user interface provides several schematic views of the 
electrical network. This is just a different presentation of the same objects modeled in the tree 
and grid views: 
•Substation Overview – This overview display shows all of the substations within a 
SubGeographicalRegion and the ACLineSegments that connect them. The substations can be 
overlaid on a geographical map based on their latitude/longitude. 
•Substation Detail – This schematic display shows the detailed model of a single substation 
and its connected equipment regardless of voltage level. 
•Voltage Level Detail – This schematic display is very similar to the substation detail except 
that it displays a single voltage level within a substation. 
•SCADA Topology – This schematic display enables the user to maintain mixed network and 
SCADA equipment, or SCADA-only topology information. 
•DC Line Overview – This overview display shows the DC network within a 
GeographicalRegion. Accessed from the Network Model or Network Connectivity trees, it 
shows Substations, DCConverters, and DCLineSegments. 
Note: While production of FG displays from the Graphic Modeler representation is a nice idea, it 
has not yet been implemented.
See e-terrasource User’s Guide, section “Graphic Modeler”.

Lab 10: Study Validation and Export 
Lab Objectives 
After completing this lab, you will be able to: 
• Understand Network Model Validation 
• Generate a netmom case from ETS.  
 
Task 1: Change Substation EMS Name 
1. Create a new Project xxxx_Validation (where xxxx is a personal identifier), 
and make it your active project. 
2. Call up the Network Model tree view. 
3. Expand the tree nodes by clicking the “>” symbol in the following 
sequence: Network Model → NEPOOL → SubGeographical Region → 
EAST → Substation → CLASS. 
4. In the Identification properties of substation CLASS, try to enter 
CLASS_TEST in the “EMS Name” field. Can you enter more than 8 
characters? 
  
Task 2: Change Base Voltage EMS Name 
1. Call up the Table tree view. 
2. Expand the tree nodes in the following sequence: Network → Network 
Reference Tables → BaseVoltage. 
3. Change the Base Voltage 138 EMSName from 138 to 345. Save the 
change you made. What is the pop-up error message? 
 
Task 3: Change the AmpRating for DCConverter 
1. Click the Table button in the toolbar. 
2. In the Table Explorer window, expand Network → Power System 
Equipment →DCConverter. 
3. In the column AmpRating for any DCConverter, change the value to -5. 
4. The box should turn red and there should be an error message. What is 
it?

Task 4: Delete Child Record for Line 
1. Click the Network->Network Model in the toolbar. 
2. Locate a line and remove all of its child record. 
3. Save the changes to an active project 
4. Run Workspace Validation>Network Validation. What is the error 
message? 
 
Task 5: Export Netmom Case to EMP 
1. Reset your workspace. 
2. Load the EMP60 MAS v1 into your workspace. 
3. Create a new project xxx_Export. 
4. Navigate to the Substation HEARN and change the EMSName to 
ETSTEST. 
5. Click the export icon from the toolbar, and select Export Workspace. 
6. In the popup window, select EMS Export – Netmom, select the right EMP 
version,then click Finish button to start the export process. 
7. After the export process is successful, use HDBRIO to check there is a 
substation named ETSTEST.
