# Suplemento S1. Matriz de extracción y codificación de atribuciones

Unidad de análisis: numeral de atribución de cada ficha del Manual de Organización. Se codificaron todos los numerales de las veinte fichas, pertinentes o no, para que el recuento sea reproducible. El signo «?» marca un objeto que el texto no delimita.

Codificación realizada por un solo codificador. Queda pendiente una segunda codificación independiente y el cálculo de concordancia (kappa de Cohen) por variable.

## Libro de códigos

**Dominio (objeto)**

| Código | Significado |
|---|---|
| ME | Modelo eléctrico |
| TT | Telemetría y telecontrol |
| CO | Comunicaciones |
| AP | Aplicaciones EMS |
| PT | Plataforma técnica |
| GS | Gobierno y seguridad |
| OR | Operación del sistema y criterios operativos |
| - | Fuera del objeto SCADA/EMS |

**Fase del ciclo de cambio**

| Código | Significado |
|---|---|
| PLA | Planificación y proyecto |
| REQ | Requisito |
| CON | Diseño y construcción |
| INT | Integración e implementación |
| PRU | Prueba |
| ACE | Aceptación o recepción |
| LIB | Liberación o habilitación |
| DES | Despliegue y puesta en servicio |
| OPE | Operación, soporte y mantenimiento |
| REG | Registro y documentación |

**Tipo de autoridad**

| Código | Significado |
|---|---|
| EJE | Ejecuta |
| SUP | Supervisa |
| REV | Revisa o verifica |
| APR | Aprueba |
| ADM | Administra o gestiona |
| AUT | Autoriza o suspende en tiempo real |
| COO | Coordina |
| SOP | Soporte o apoyo |
| SOL | Solicita o recomienda |
| DEF | Define criterios, normas o políticas |

**Pertinencia para el cambio de base SCADA/EMS**

| Código | Significado |
|---|---|
| D | Directa |
| I | Indirecta |
| N | No pertinente |

Reglas: (1) se codifica el verbo rector literal; (2) si un numeral tiene varios verbos, se registran todos; (3) el dominio se asigna por el objeto nombrado, no por la unidad; (4) la pertinencia es directa si el numeral actúa sobre la base, las aplicaciones o su cambio, indirecta si aporta insumos, criterios o contexto, y nula en otro caso; (5) dos numerales se comparan solo si comparten al menos un dominio y una fase.
